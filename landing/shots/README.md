# Screenshots for the landing page

Drop four PNGs here, named exactly:

| File | What to capture |
|------|-----------------|
| `library.png` | A library view with rows of posters, artwork loaded |
| `detail.png`  | A film or series detail page: artwork, cast, episodes |
| `player.png`  | The player, controls visible, subtitle/audio menu open |
| `recap.png`   | The yearly recap |

Take them at **1600×900** (or any 16:9 — the page scales them) in a
maximised window, dark theme, with the browser chrome cropped out.

Two things to check before saving:

- **No personal data.** No account name, no email, no file paths, and nothing
  from the Streaming section — a resolved source URL carries a debrid token.
- Nothing in shot that you would not put on a billboard: the page is public.

Run them through an optimiser (`squoosh`, `pngquant`) if they come out over
~400 KB each. They are lazy-loaded, but the page should still feel instant.
